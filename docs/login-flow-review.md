# 登录流程调整与验证

日期：2026-09-08。此次变更以用户下午提出的登录流程为准，代码保存在当前工作区，未提交或发布。

## 最终行为

- 每次启动先显示同一个无系统标题栏的登录窗口，旧会话令牌不会跳过登录。Windows 全局模式提权重启也遵循这一规则。
- 整个登录窗口使用 Windows 原生圆角、浅灰绿细边框和外阴影，首次显示及从托盘恢复时重新应用；内容保持不透明，避免软件渲染时产生透明白角。圆角和边框颜色由支持这些属性的 Windows 版本绘制（[Winit Windows 窗口接口](https://docs.rs/winit/0.30.13/x86_64-pc-windows-msvc/winit/platform/windows/trait.WindowExtWindows.html)）。
- 在登录页面加载启动配置、读取用户明确保存的登录信息；配置与服务初始化成功之前，按钮和回车登录均不可用。失败时在页面内提示并提供重试。
- 发现更新时在登录页显示共享升级弹窗。升级判断早于业务 API 探测和登录；本次启动的自动登录被取消，选择“稍后再说”后需要手动登录。强制更新不能跳过。
- 勾选“自动登录”并成功登录后，将邮箱和密码一起保存到独立的系统凭据项。下次启动自动填入邮箱与密码（密码遮挡显示），待配置就绪且没有更新、没有用户编辑时，等待完整 2 秒调用与按钮相同的登录入口。
- 自动登录使用 18px 圆角复选框、36px 高点击区域、品牌绿色选中状态与键盘焦点样式。复选框与加载/倒计时提示同处固定高度的一行，保持输入框和登录按钮的间距稳定。
- 修改输入、取消勾选或出现更新提示都会停止倒计时。自动登录只尝试一次，失败后等待手动操作；取消勾选、退出账号和成功修改密码会清除保存的登录信息。
- 自动登录输入不写入 TOML、启动 JSON 或日志；损坏、不兼容的保存内容会清除，凭据库不可用时仍可手动登录。

## 验证

直接运行 Windows 构建，观察截图、控件状态与窗口标识，确认线上测试版本 100 在登录页弹窗，选择“稍后再说”后显示服务加载状态，配置完成后保持同一窗口及登录表单。无旧会话自动跳转。

最终构建首次启动已实测显示整窗圆角和细边框；窗口样式在原生窗口创建完成后应用，修复了早于事件循环设置而只在恢复窗口后生效的问题。新复选框已实测鼠标勾选、空格取消及键盘焦点，错误/重试与加载提示在同一行对齐，登录按钮不随状态变化移动。

使用相同 Slint 组件的本地预览验证：保存的输入能填入且密码遮挡；配置未完成时即使输入完整仍禁用登录；更新取消后等待超过 2 秒仍无自动登录；自动倒计时只调用一次登录回调。

新增可控时钟的 Slint 界面测试，直接验证真实组件的 Timer：1,999 毫秒不提交，2,000 毫秒提交一次；配置、更新、取消勾选、编辑输入及已登录状态均拦截相应提交。新增凭据存储测试覆盖保存/读取/清除、损坏内容、版本不兼容、大小限制及日志脱敏。

凭据操作还覆盖了取消/超时边界：调用方结束等待后，仍在执行的系统凭据操作继续持有串行锁，直到实际完成，避免旧读取任务与后续保存或清除互相覆盖；对应并发回归测试通过。

没有输入真实账号密码或向生产登录接口提交测试凭据；成功登录后的真实系统凭据持久化未做端到端认证测试，存储和计时逻辑由上述自动化测试覆盖。

最终检查：`cargo fmt --all --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace`、`cargo build -p topnode-desktop` 均通过；工作区 211 项测试通过，1 项线上集成测试按默认设置忽略。28 个 Slint 文件编译检查及 `git diff --check` 通过。

## 窗口控件与升级焦点补充

- 升级弹窗打开时将焦点留在弹窗自身，不默认高亮“稍后再说”或“退出应用”。初始回车不触发操作；Tab 从次要按钮开始，Shift+Tab 从升级按钮开始，之后焦点在可用按钮之间循环。Esc 仍仅用于关闭可选更新。
- 登录后继续使用无系统标题栏的同一个窗口与原生外边框。共享的 `WindowControls` 在主页采用 40px 紧凑标题区，提供拖动、最小化和关闭；品牌标识继续由左侧导航显示。
- 右侧页面内容单独避让标题区，主页底部状态栏、设置页全部开关、个人中心均通过真实 Slint 窗口预览检查，遮罩仍覆盖整个窗口。
- 自定义关闭按钮和系统关闭请求共用关闭逻辑：登录阶段退出程序，已登录阶段隐藏到托盘。
