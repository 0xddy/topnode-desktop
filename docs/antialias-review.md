# 圆角描边与导航焦点检查

日期：2026-09-08。

## 修改

- 软件渲染器原有圆角描边使用整数物理线宽和较粗的覆盖率近似，1.5px 的选中描边在 100% 缩放下会截断。套餐、节点和公共 `SurfaceCard` 改用 `SmoothCard` 的统一 1px 描边。
- 四个 SVG 圆角独立按显示尺寸栅格化，直边单独绘制。几何接点对齐物理像素，非整数缩放的不足一像素内边缘按覆盖率混色，避免把 1.5 个物理像素直接加粗为 2 个。保留原背景、阴影、布局及局部刷新机制。
- 支持现有 10、12、16、20、22、24px 半径；其他半径和过小尺寸回退到普通圆角描边。透明、无描边的支付和购买卡片保留原状态。
- 导航点击后不再出现焦点外框。选中项保留浅绿背景和左侧标记；Tab 焦点使用浅色背景提示，Enter/空格操作仍保留。
- 没有改字体、文字抗锯齿算法、Windows 系统缩放或渲染后端。
